# Store Assistant demo

English browser-only preview with a sample product catalog and scripted chat replies. No accounts, credentials, API calls, database, or Shopify connection are required. Chats and appearance preferences are stored in the visitor’s browser.

To publish with GitHub Pages, upload the contents of this directory to the root of a public GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.
